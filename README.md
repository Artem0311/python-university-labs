# findex — пошукова система на Python

`findex` — навчальна пошукова система з інвертованим індексом, BM25, TF-IDF, асинхронним краулером і вебінтерфейсом.

**Живий сервіс:** https://python-university-labs.onrender.com/

| Документів | p95 Render | Найкраще прискорення |
|---:|---:|---:|
| 14 | 926.40 мс | 1.16× |

p95 — вимірювання лабораторної №7. Прискорення — BM25 на частому терміні, лабораторна №8.

## Архітектура

~~~mermaid
flowchart LR
    A[Вебсторінки] --> B[Краулер]
    B --> C[Корпус]
    D[Локальні документи] --> C
    C --> E[Токенізатор]
    E --> F[Інвертований індекс]
    F --> G[BM25 / TF-IDF]
    G --> H[FastAPI]
    H --> I[Сторінка пошуку]
~~~

## Запуск

~~~bash
cd findex
uv sync
uv run findex index data/ --out data/index.bin
uv run findex search data/index.bin "програмування"
~~~
